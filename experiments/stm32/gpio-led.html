EXPERIMENT 01 · STM32 GPIO

GPIO 点灯实验

使用 STM32F103C8T6 的 PC13 引脚控制板载 LED 周期性亮灭，完成从 CubeMX 配置、HAL 程序编写到 Keil 编译下载的完整流程。

难度：入门 建议课时：1 学时 芯片：STM32F103C8T6 HAL 库：STM32CubeF1 V1.8.7

1. 实验目标

  • 认识 STM32 GPIO 的输出功能，理解推挽输出、高低电平和输出速度等基本概念。
  • 能够在 STM32CubeMX 中选择芯片并将 PC13 配置为 GPIO 输出。
  • 掌握 HAL_GPIO_TogglePin() 和 HAL_Delay() 的基本使用方法。
  • 能够使用 Keil MDK 完成工程编译，并通过 ST-Link 将程序下载到开发板。
  • 能够根据 LED 现象排查供电、接线、下载器和程序配置问题。

2. 所需软硬件与适用开发板

硬件

  • STM32F103C8T6 最小系统板或采用该芯片的课程开发板
  • 板载 LED 连接至 PC13 的开发板
  • ST-Link V2 下载器及杜邦线
  • USB 供电线（按开发板接口选择）

软件

  • STM32CubeMX 6.17.0
  • STM32CubeF1 固件包 V1.8.7
  • Keil µVision 5.36
  • Arm Compiler 5.06 update 7
  • ST-Link 驱动程序
适用性说明：本实验依据参考工程中的 STM32F103C8T6 和 PC13 编写。若你的开发板 LED 接在 PB0、PA8 等其他引脚，应在 CubeMX 和程序中同步修改端口与引脚。

4. STM32CubeMX 配置步骤

  1. 启动 STM32CubeMX，选择 File → New Project → MCU Selector。
  2. 搜索并选择 STM32F103C8Tx，封装为 LQFP48。
  3. 在 Pinout 视图中点击 PC13，选择 GPIO_Output。
  4. 进入 System Core → SYS，将 Debug 设置为 Serial Wire，保留 PA13 和 PA14 作为 SWD 引脚。
  5. 进入 System Core → GPIO，确认 PC13 为 Output Push Pull、No pull-up and no pull-down、Low output speed。
  6. 进入 System Core → RCC，将 High Speed Clock（HSE）设置为 Crystal/Ceramic Resonator。
  7. 进入 Clock Configuration：选择 HSE 作为 PLL 时钟源，将 PLL 倍频设置为 ×9，系统时钟配置为 72 MHz；APB1 分频设为 ÷2（36 MHz），APB2 保持 ÷1（72 MHz）。
  8. 在 Project Manager 中设置工程名 Car_STM32F1_HAL，Toolchain/IDE 选择 MDK-ARM V5。
  9. 勾选 Keep User Code when re-generating，点击 Generate Code 生成工程。
时钟配置结果：参考工程使用 8 MHz 外部晶振，经 PLL×9 得到 72 MHz SYSCLK；AHB 为 72 MHz、APB1 为 36 MHz、APB2 为 72 MHz。若开发板没有外部晶振，应改用 HSI 配置，否则程序可能停在 Error_Handler()。

5. 程序编写位置与关键代码

打开 Core/Src/main.c。CubeMX 已在初始化阶段调用 MX_GPIO_Init()，因此只需要在主循环的用户代码区加入 LED 翻转和延时。

5.1 GPIO 初始化代码

以下代码由 CubeMX 自动生成，位于 Core/Src/gpio.c：

void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  __HAL_RCC_GPIOC_CLK_ENABLE();

  HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET);

  GPIO_InitStruct.Pin = GPIO_PIN_13;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
}

5.2 主循环代码

将代码写在 /* USER CODE BEGIN 3 */ 保护区内，避免重新生成工程时被覆盖：

/* Infinite loop */
/* USER CODE BEGIN WHILE */
while (1)
{
  /* USER CODE END WHILE */

  /* USER CODE BEGIN 3 */
  HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
  HAL_Delay(500);
}
/* USER CODE END 3 */
代码说明：HAL_GPIO_TogglePin() 每执行一次就翻转 PC13 输出电平；HAL_Delay(500) 延时 500 ms。LED 每 0.5 秒切换一次状态，因此一个完整亮灭周期约为 1 秒。
代码位置已核对：修改后的参考工程已将两条 LED 语句放入 USER CODE BEGIN 3 保护区，重新用 CubeMX 生成代码时可保留这部分用户程序。

6. 编译和下载步骤

  1. 进入工程的 MDK-ARM 文件夹，双击 Car_STM32F1_HAL.uvprojx。
  2. 在 Keil 中确认目标芯片为 STM32F103C8，并确认已安装 STM32F1xx Device Family Pack。
  3. 点击 Rebuild 或按 F7 编译；输出窗口应显示 0 Error(s), 0 Warning(s)。
  4. 连接 ST-Link：SWDIO→PA13、SWCLK→PA14、GND→GND，并为目标板提供正确的 3.3V 电源。
  5. 打开 Options for Target → Debug，选择 ST-Link Debugger。
  6. 在 Utilities 中选择使用 ST-Link 下载，并确认 Flash Programming Algorithm 包含 STM32F10x 对应算法。
  7. 点击 Download 或按 F8，等待显示 Programming Done / Verify OK。
  8. 复位开发板，观察 PC13 板载 LED。
参考工程验证结果：修改后的工程已于 2026-11-18 使用 Keil µVision 5.36、Arm Compiler 5.06 update 7 构建成功，结果为 0 错误、0 警告，并已生成最新 HEX 文件。

7. 预期实验现象

正常现象

程序下载并复位后，PC13 对应的板载 LED 以约 500 ms 的间隔交替亮、灭，即约每秒完成一个完整闪烁周期。

观察记录

将 HAL_Delay(500) 分别改为 100、1000 和 2000，重新编译下载，比较不同延时时间下的闪烁速度。

8. 常见问题与排查

LED 一直不亮

先确认 LED 是否真的连接到 PC13，再检查开发板供电、GND 共地和程序是否成功下载。部分开发板的 LED 连接在其他引脚，应修改 CubeMX 和代码。

LED 一直亮、不闪烁

检查主循环内是否同时包含 HAL_GPIO_TogglePin() 和 HAL_Delay()；确认程序已重新编译、下载，并且下载的是当前工程生成的新文件。

Keil 提示 Target not found 或无法连接 ST-Link

依次检查 ST-Link 驱动、SWDIO/SWCLK 接线、3.3V 供电和公共地；在 Debug Settings 中尝试降低 SWD Clock。若程序关闭了调试口，可按住复位键连接后再释放。

编译提示缺少设备包或头文件

安装 Keil STM32F1xx Device Family Pack，并确认工程 Include Paths 中包含 Core/Inc、HAL Driver 和 CMSIS 目录。参考工程使用 Keil.STM32F1xx_DFP 2.4.1。

重新用 CubeMX 生成代码后，点灯程序消失

自定义代码必须写在 USER CODE BEGIN 与 USER CODE END 之间。本实验建议放在主循环的 USER CODE BEGIN 3 区域。

LED 的亮灭逻辑与预期相反

这是低电平点亮电路的正常现象。需要固定控制时，可使用 GPIO_PIN_RESET 点亮、GPIO_PIN_SET 熄灭；使用 Toggle 时只关注闪烁即可。

9. 提高任务

任务 A：改变闪烁频率

修改延时时间，实现快速闪烁、慢速闪烁和“短亮长灭”的节奏效果，并记录各阶段持续时间。

任务 B：三色流水灯

增加三个外接 LED，建议使用普通 GPIO 引脚并分别串联限流电阻，编写红、绿、蓝依次点亮的流水灯程序。

任务 C：按键控制 LED

增加一个 GPIO 输入引脚，读取按键状态，实现按下一次切换一次 LED 状态，并思考按键消抖问题。

任务 D：PWM 呼吸灯

将 LED 改接到支持定时器 PWM 输出的引脚，通过逐步改变占空比实现亮度渐变。PC13 不适合作为硬件 PWM 输出。
